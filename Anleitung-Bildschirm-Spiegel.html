Micro:Bit-Emulator: Bildschirm-Spiegel

Sensoren auslösen, Muster anzeigen – gross auf dem Bildschirm gespiegelt.

Ziel

Ein BBC Micro:Bit misst mit seinen Sensoren die Umgebung. Ein Ereignis (z.B. ein Knopfdruck oder ein Objekt vor dem Ultraschallsensor) löst ein Muster auf der 5×5-LED-Matrix aus – etwa ein Herz. Dieses Bild wird live und gross auf einen Bildschirm oder Beamer gespiegelt. So wird für alle sichtbar, wie ein Micro:Bit auf seine Sensoren reagiert.

Material

BBC Micro:Bit v2
Version 2 (mit Mikrofon), für Ton-Reaktionen.
USB-Datenkabel
Micro-USB – wichtig: Datenkabel, kein reines Ladekabel.
Anzeige-Rechner
PC, Laptop oder Raspberry Pi mit Chrome oder Edge.
Bildschirm oder Beamer
Zeigt die vergrösserte Matrix.
Grove-Shield + Sensor optional
z.B. Grove-Ultraschall-Abstandssensor für ein Publikums-Exponat.
Gehäuse / Ständer optional
Lasergeschnitten oder 3D-gedruckt, Micro:Bit vorne sichtbar.

Software – drei Teile

Das Projekt besteht aus einer MakeCode-Erweiterung (spiegelt die Matrix), einem MakeCode-Programm auf dem Micro:Bit und einer HTML-Anzeigeseite, die im Browser läuft – komplett offline, ohne Cloud.

Schritt für Schritt

1

Hardware verbinden

Micro:Bit mit dem USB-Datenkabel an den Anzeige-Rechner anschliessen. Bei Grove-Nutzung zuerst das Grove-Shield auf den Micro:Bit stecken und den Sensor am passenden Port anschliessen.

2

Erweiterung „Bildschirm-Spiegel" hinzufügen

In makecode.microbit.org ein Projekt öffnen, dann Zahnrad → Erweiterungen. Die GitHub-URL der Erweiterung einfügen und hinzufügen. Danach erscheint die Kategorie Bildschirm-Spiegel.

Repo-URL: https://github.com/DEINNAME/pxt-bildschirm-spiegel

3

Programm schreiben und flashen

Den Block Bildschirm-Spiegel starten an den Anfang legen. Danach die eigene Logik – hier ein Beispiel mit den Tasten A/B und dem Senden der Sensorwerte:

input.onButtonPressed(Button.A, function () {
    basic.showIcon(IconNames.Happy)
})
input.onButtonPressed(Button.B, function () {
    basic.showIcon(IconNames.Sad)
})
bildschirmSpiegel.starten()
basic.forever(function () {
    bildschirmSpiegel.werteSenden(
        input.temperature(), input.lightLevel(), input.soundLevel())
    basic.pause(200)
})

Wichtig: die basic.pause(200) in der Schleife nicht vergessen – ohne Pause werden die Sensoren zu schnell ausgelesen und die Werte zappeln.

4

Anzeige öffnen und verbinden

Die Datei microbit-matrix-display.html in Chrome oder Edge öffnen, auf Verbinden klicken und den Micro:Bit (USB) auswählen. Die Matrix erscheint gross, rechts die Sensorwerte. Mit Vollbild und Daten ausblenden wird daraus die reine Grossanzeige fürs Exponat.

5

Grove-Ultraschall ergänzen (optional)

Sensor am Port P0 anschliessen, die Erweiterung grove hinzufügen und den Abstand messen, anzeigen und senden:

bildschirmSpiegel.starten()
basic.forever(function () {
    let d = grove.measureInCentimeters(DigitalPin.P0)
    bildschirmSpiegel.abstandSenden(d)
    if (d > 0 && d < 15) {
        basic.showIcon(IconNames.Heart)
    } else if (d > 0 && d < 40) {
        basic.showIcon(IconNames.SmallHeart)
    } else {
        basic.clearScreen()
    }
    basic.pause(100)
})
6

Als Exponat aufbauen

Micro:Bit und Bildschirm nebeneinander aufstellen (die kleine echte Matrix und der grosse Screen ergeben einen schönen Aha-Effekt), fest verkabeln und ein Erklärschild dazustellen. Als Ruhezustand eignet sich ein kleines pulsierendes Herz, damit das Exponat auch ohne Besucher einladend wirkt.

Wenn etwas klemmt

  • Kein „Verbinden" möglich: Web Serial gibt es nur in Chrome/Edge, nicht in Firefox/Safari.
  • Micro:Bit wird nicht gefunden: anderes USB-Kabel testen – viele Kabel sind reine Ladekabel ohne Datenleitungen.
  • Werte zappeln: basic.pause(200) in der Schleife ergänzen.
  • Temperatur wirkt zu hoch/ungenau: Der interne Sensor misst die Chip-Temperatur, nicht die Raumluft. Für echte Raumtemperatur einen externen Grove-Sensor verwenden.
